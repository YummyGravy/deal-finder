How to set up SerpApi (2 minutes)
  1. Sign up free at serpapi.com (no credit card).
  2. Copy your API key from your SerpApi dashboard.
  3. In your GitHub repository: Settings → Secrets and variables → Actions → New repository secret. Name it SERPAPI_KEY and paste the key.
  4. For Facebook Marketplace, set Your area under Profit and area.
  5. Tick Stores or Facebook Marketplace under a search's filters.

Tips and tricks

  • Know the resale price first. Check eBay sold listings (not asking prices) or PriceCharting for retro games, then put that in "Resells for".
  • Bulk lots hide duds. Look at every photo; one rare cart can carry a lot, five common ones won't.
  • Skip words save time. repro, reproduction, for parts, broken, read description.
  • Fees and shipping eat margin. A deal under ~30% estimated profit is usually not worth the hassle.
  • Review mode is the fastest way through a big scan: one tap per deal.

Install this app

Android (Chrome)

  1. Open this page in Chrome.
  2. Tap ⋮, then Add to Home screen. If you see Install app, that works too.

iPhone and iPad (Safari)

  1. Open this page in Safari.
  2. Tap Share, then Add to Home Screen, then Add.

Windows PC (Chrome or Edge)

  1. Chrome: ⋮ → Cast, save, and share → Install page as app.
  2. Edge: ⋯ → Apps → Install this site as an app.
